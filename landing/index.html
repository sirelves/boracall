Por que BoraCall

◊

P2P de verdade

Áudio flui direto entre os peers via WebRTC, com Opus 48kHz. Sem servidor intermediando a voz até 4 pessoas — latência mínima, zero custo por minuto.

▧

Nativo nos 3 desktops

Tauri + Rust. 3MB de binário. Abre em 200ms. Não é Electron, não sobe um Chromium do zero. Usa o webview do sistema.

⎔

Sem fricção

Criar sala = um clique. Entrar = colar o link. Sem lobby, sem PIN, sem convite na agenda. Você tá na call em 5 segundos.

▤

Backend em Rust

Signaling WebSocket em axum + tokio, Postgres 16. Stateless, escala horizontal. Binário único de 4MB — cabe em qualquer VPS.

⟠

Atalhos de teclado

M mute · SPACE push-to-talk · H esconder UI · ESC sair. Modo "always on top" pra ficar visível enquanto você trabalha.

⌬

Open source

MIT. Código aberto no GitHub. Self-hostável no seu VPS em 5 minutos — Postgres, server, nginx + TLS. Sem lock-in.

Como funciona

01

Instala

Binário pequeno, não é Electron. 3-5MB dependendo do sistema. Abre direto, sem splash screen de 4 segundos.

02

Cria sala

Dá um nome, escolhe se é "rápida" (some sozinha quando esvazia) ou "fixa" (fica no seu workspace).

03

Compartilha link

boracall.com/s/ajaa1dxqpn. Quem cola num chat, clica, e cai na call. Sem pedir cadastro pro convidado.

04

Fala

WebRTC mesh P2P. Servidor só faz signaling — a voz trafega direto entre vocês. Até 4 pessoas por sala.

Perguntas frequentes

É mesmo grátis?

É. Até 4 pessoas por sala, rodando P2P, sem custo por minuto. Acima disso a gente vai precisar de um SFU (servidor que agrega áudio) — aí provavelmente roda um plano pago. Pra call de time pequeno, nunca vai cobrar.

Precisa criar conta?

Sim pra criar salas. Não pra entrar numa sala que alguém compartilhou com você. Quem recebe o link só coloca um nome e entra.

Vocês gravam as chamadas?

Não. A voz nem passa pelo servidor — é P2P direto entre os peers. O server só conhece quem entrou em que sala. Logs de presença ficam 30 dias pra debug e são apagados.

O app é open source?

Sim, MIT. github.com/boracall/boracall. Você pode auditar, rodar seu próprio server, ou fazer fork.

E Windows e Linux de ARM?

Tem. Link acima em "também tem…". Raspberry Pi 4+ e Asahi Linux rodam tranquilo. Windows ARM (Surface Pro X, etc.) também.

Posso usar pra mobile?

Ainda não — o Tauri tem build pra iOS/Android mas a gente não empacotou. Entrar numa call do navegador do celular funciona hoje (boracall.com/s/<slug> abre a PWA). App nativo mobile tá no roadmap.

Como roda no meu próprio servidor?

3 comandos numa VPS Ubuntu com Docker: clone o repo, docker-compose up -d postgres, cargo run -p boracall-server --release. Nginx na frente com TLS, dist/env.js apontando pro seu domínio. Guia completo no HANDOFF.md.
